 # NoBS Cert Prep

A small, responsive static website starter for a plain-language certification-prep brand. It contains a home page, Security+ overview, pricing page, sample lesson, and shared stylesheet.

## Files

- `index.html` — home page
- `security-plus.html` — guide overview and topic outline
- `pricing.html` — pricing layout with clearly marked placeholders
- `guide-sample.html` — sample lesson on least privilege
- `style.css` — shared responsive styles

## View locally

Save all five files in the same folder, then open `index.html` in a modern web browser. No build step, external library, or server is required.

## Before publishing

1. Replace the pricing placeholder with accurate product pricing, terms, and delivery details.
2. Connect a real, secure checkout flow before accepting payments; this starter does not process payments.
3. Review and update lesson content against the current official exam objectives. Do not represent this independent resource as official CompTIA material.
4. Add any desired privacy, contact, accessibility, and business information pages.
5. Upload the files together to your chosen static hosting provider, preserving the filenames and links.
